# 新实验报告：Projected Log-Signature Forecast for Sibylla

## 实验名称

- 中文名：新实验，投影式 Log-Signature 前瞻诊断实验
- 图像标题：`New Experiment: Sibylla Projected Log-Signature Forecast`
- 实验脚本：`run_projected_logsig_experiment.py`
- 输出目录：`sibylla_experiment/results_projected_logsig/`

## 实验原理

这个实验比老实验更接近您最初设想的 Sibylla 设计。它验证的是：

> 在高维潜轨迹场景中，如果先把轨迹投影到低维，再结合历史窗口和一步前瞻期望来诊断几何复杂度，最后自适应选择 `log-signature` 阶数，是否能同时提升效果并控制复杂度。

核心流程如下：

1. 先在高维潜空间中构造轨迹，再投影到低维空间 `R^{d_proj}`。
2. 用投影后的历史窗口，再拼接一个基于速度和加速度外推得到的“一步前瞻期望点”。
3. 对这个诊断窗口计算弧弦比 `R = arc / chord`。
4. 按阈值分配阶数：
   - `R < 1.1 -> m = 1`
   - `1.1 <= R < 1.5 -> m = 2`
   - `R >= 1.5 -> m = 3`
5. 对窗口计算截断 `log-signature`。
6. 为了保证后续 MLP 输入宽度固定，只计算到建议阶数，然后把更高阶特征位置全部零填充到最大三阶宽度。

相对于老实验，这个版本增加了三项关键增强：

- 高维潜轨迹 + 低秩投影
- 历史窗口 + 一步前瞻期望
- 普通 signature 改为 `log-signature`

因此它更接近真正的 Sibylla 几何诊断模块，而不只是二维玩具例子。

## 实验结果

本次结果如下：

| 条件 | overall RMSE | straight RMSE | curve RMSE | spiral RMSE | avg feature dim |
|---|---:|---:|---:|---:|---:|
| `fixed_m1` | 1.254861 | 0.105670 | 0.737755 | 2.041710 | 3.000000 |
| `fixed_m2` | 0.243725 | 0.102173 | 0.110367 | 0.394443 | 12.000000 |
| `fixed_m3` | 0.081500 | 0.100304 | 0.072500 | 0.067895 | 39.000000 |
| `adaptive_sibylla` | 0.045127 | 0.037879 | 0.038181 | 0.056716 | 18.000000 |

额外现象：

- 平均蜿蜒度大致为：
  - `straight ≈ 1.011`
  - `curve ≈ 1.190`
  - `spiral ≈ 4.549`
- 自适应策略在当前测试集里三种阶数使用比例接近均分。

结论：

- 在更困难、更接近设想的设定下，`adaptive_sibylla` 仍然最好。
- 它比 `fixed_m3` 的总体误差更低。
- 同时它的平均活跃特征维度 `18` 明显低于 `fixed_m3` 的 `39`。

因此这份新实验支持如下判断：

> Sibylla 的“先诊断，再分配阶数”不只是老原型里有效，在更严格的投影 + 前瞻 + log-signature 设定下也有效。

但仍然要保留一个实验学上的限制：

- 这依然是合成数据实验；
- 数据簇和目标结构仍然是人为设计的；
- 所以它是强于老实验的验证，但还不是对真实任务的最终证明。

## 读图方式

这张图有四个子图，也不是“全部越高越好”。

### 1. Overall RMSE

- 含义：总体误差。
- 读法：**越低越好**。
- 核心结论：`adaptive` 最低，说明总体效果最好。

### 2. Sibylla Order Usage

- 含义：自适应策略中，三种阶数被使用的比例。
- 读法：不是评分项，**没有越高越好或越低越好**。
- 作用：解释 Sibylla 在数据集上的决策分布。

### 3. Winding Ratio Thresholds

- 含义：每个样本的蜿蜒度指标 `R`。
- 两条虚线：
  - `1.1`
  - `1.5`
- 读法：
  - 落在 `1.1` 以下，建议 `m=1`
  - 落在 `1.1` 到 `1.5` 之间，建议 `m=2`
  - 超过 `1.5`，建议 `m=3`
- 这个图同样不是好坏分数。
- 它的作用是说明：Sibylla 的分阶建议是否真的按轨迹复杂度在工作。

### 4. Compute Cost

- 左轴柱状图：平均活跃特征维度。
- 右轴折线：特征构造耗时。
- 读法：通常 **越低越省**。
- 正确比较方式：
  - 先看 `RMSE` 是否低；
  - 再看计算成本是否比高阶固定方案更小。

在这次新实验里：

- `fixed_m3` 误差已经不差，但成本最高；
- `adaptive_sibylla` 误差更低，同时成本明显更低；
- 这正是 Sibylla 设计想达到的平衡。

## 本实验想说明什么

新实验主要说明：

> 即使在更复杂的高维轨迹投影和前瞻诊断条件下，基于弧弦比的自适应阶数选择仍然成立，而且确实带来“更低误差 + 更低平均复杂度”的收益。

和老实验相比，它更接近真正模块落地前应有的验证形式。
