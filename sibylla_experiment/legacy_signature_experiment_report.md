# 老实验报告：2D Signature Prototype for Sibylla

## 实验名称

- 中文名：老实验，二维 Signature 原型
- 图像标题：`Legacy Experiment: 2D Signature Prototype for Sibylla`
- 实验脚本：`run_legacy_signature_experiment.py`
- 输出目录：`sibylla_experiment/results_legacy/`

## 实验原理

这个实验是 Sibylla 想法的第一版原型，目标是验证一句话：

> 如果轨迹几何复杂度不同，那么让系统先诊断复杂度，再决定签名截断阶数，会不会比固定只用一阶、二阶或三阶更好。

它的做法比较直接：

1. 在二维空间中人工生成三类轨迹：
   - `straight`：近似直线
   - `curve`：明显弯曲
   - `spiral`：盘旋轨迹
2. 对每条轨迹计算弧弦比 `R = arc / chord`，作为蜿蜒度指标。
3. 用阈值分配阶数：
   - `R < 1.1 -> m = 1`
   - `1.1 <= R < 1.5 -> m = 2`
   - `R >= 1.5 -> m = 3`
4. 构造四个对照条件：
   - `fixed_m1`：所有样本都只用一阶 signature
   - `fixed_m2`：所有样本都固定用到二阶 signature
   - `fixed_m3`：所有样本都固定用到三阶 signature
   - `adaptive_sibylla`：每个样本先算 `R`，再自适应选择阶数
5. 为了让后续 MLP 输入维度固定，实验对低阶特征采用零填充，统一补到三阶最大宽度。

这个实验使用的是 **普通截断 signature**，不是 `log-signature`；也没有高维潜轨迹投影和一步前瞻窗口。

## 实验结果

本次结果如下：

| 条件 | overall RMSE | straight RMSE | curve RMSE | spiral RMSE | avg feature dim |
|---|---:|---:|---:|---:|---:|
| `fixed_m1` | 0.443150 | 0.470908 | 0.353660 | 0.492256 | 2.000000 |
| `fixed_m2` | 0.065388 | 0.028244 | 0.072809 | 0.082023 | 6.000000 |
| `fixed_m3` | 0.077867 | 0.037667 | 0.123414 | 0.039241 | 14.000000 |
| `adaptive_sibylla` | 0.005186 | 0.001665 | 0.003713 | 0.008008 | 7.333333 |

结论：

- 这个老实验里，`adaptive_sibylla` 明显最好。
- 它不仅误差最低，而且平均维度远低于固定三阶。
- 这说明“先诊断轨迹复杂度，再分配阶数”的核心思路在原型场景下是成立的。

但要注意，这个实验比较理想化：

- 数据就是按复杂度分三类构造的；
- 目标信号也和一阶、二阶、三阶结构高度对齐；
- 因此自适应策略的优势会被放大。

所以这份实验更适合作为 **机制验证**，而不是最终证明。

## 读图方式

这张图只有三个子图，不是“全部越高越好”。

### 1. Overall RMSE

- 含义：总体误差。
- 读法：**越低越好**。
- 结论：谁最低，谁总体效果最好。

### 2. Sibylla Order Usage

- 含义：自适应策略中，`m=1/2/3` 各被用了多少比例。
- 读法：这不是分数，**没有越高越好或越低越好**。
- 作用：只是解释 Sibylla 在这个数据集上更偏好用哪一阶。

### 3. Compute Cost

- 左轴柱状图：平均活跃特征维度。
- 右轴折线：构造特征所花的时间。
- 读法：这部分通常是 **越低越省**。
- 但不能单独看，必须和 `RMSE` 一起看。

正确的看法是：

- 如果某个方法 `RMSE` 很低，同时计算成本也不高，那它才真正有优势。
- 在这个老实验里，`adaptive_sibylla` 正是这种情况。

## 本实验想说明什么

老实验主要说明：

> 动态阶数选择本身是有价值的。

它还没有回答更复杂的问题，例如：

- 高维潜轨迹投影后是否仍然成立；
- 一步前瞻诊断是否有效；
- `log-signature` 是否仍然支持这套结论。

这些问题由新实验继续回答。
