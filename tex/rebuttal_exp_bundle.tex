\section*{Purpose}
This document indexes the curated experiment bundle placed under
\texttt{Experiments/Rebuttal/rebuttal\_exp\_anonymous/}. The goal is to expose, in one anonymous location,
the original scripts, frozen paper outputs, and rebuttal-only results that answer the main concerns
raised by reviewers \texttt{5p9M}, \texttt{kzcn}, \texttt{GqZq}, and \texttt{Bg6X}.

\paragraph{Sanitization note.}
Machine-specific absolute paths and local launcher paths were replaced with relative or placeholder paths in this anonymous export.

\section*{Directory Layout}
\begin{itemize}[leftmargin=1.5em]
\item \texttt{shared/rebuttal\_results/}: new results added specifically for rebuttal
\item \texttt{shared/original\_scripts/}: original local experiment scripts from \texttt{Experiments/}
\item \texttt{shared/frozen\_outputs/}: CSV/figure exports already materialized for the paper
\item \texttt{reviewers/}: reviewer-specific lightweight folders with the most relevant artifacts
\item \texttt{tex/rebuttal\_exp\_bundle.tex}: this overview document
\end{itemize}

Some original experiments are preserved locally mainly as scripts, while the exact CSV/figure outputs used in
the manuscript were already exported under \texttt{Paper/LaTEX/icml2026/Tables/} and
\texttt{Paper/LaTEX/icml2026/Figures/}. To make reviewer verification easier, those frozen exports are copied here.

\begin{itemize}[leftmargin=1.5em]
\item High-dimensional results: \texttt{table\_exp5\_tail\_summary.csv}
